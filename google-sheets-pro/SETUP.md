# הגדרת מנויי Pro דרך Google Sheets

במקום לערוך את `pro.txt` ולדחוף ל-git בכל פעם שרוצים לתת למישהו מנוי Pro, אפשר לנהל את זה
בגיליון Google Sheets רגיל, שהאתר קורא ממנו ישירות. עדכון בגיליון משפיע מיידית — בלי לפרוס
מחדש את האתר.

## שלב 1 — צור את הגיליון

1. פתח [sheets.google.com](https://sheets.google.com) וצור גיליון חדש (אפשר לקרוא לו "NeverLost Pro").
2. בשורה הראשונה הוסף כותרות: `Email` | `Limit` | `Expiry` | `Days left`
3. מהשורה השנייה ואילך, הוסף שורה לכל מנוי:

   | Email | Limit | Expiry | Days left |
   |---|---|---|---|
   | rb077858@gmail.com | + | | |
   | someone@example.com | 20 | | |
   | trial@example.com | 5 | 31/12/2026 | (נוסחה, ראו למטה) |

   - `Limit` — מספר תגים, או `+` לכמות בלתי מוגבלת.
   - `Expiry` — אופציונלי, בפורמט `DD/MM/YYYY` (למשל `01/01/1990`). **תא ריק = בלי תפוגה בכלל, לעולם לא פג.**
   - אפשר גם להקליד בעמודת Expiry **מספר בלבד** (למשל `30`) — אחרי כ-5 שניות הוא יתחלף אוטומטית
     בתאריך שהוא היום + אותו מספר ימים (כלומר `30` הופך לתאריך שהוא עוד 30 יום מהיום). זה קורה
     אוטומטית בזכות ה-`onEdit` שבתוך `Code.gs`, ולא דורש שום פעולה נוספת מלבד הדבקת הסקריפט (שלב 2).
   - אפשר להוסיף כמה שורות לאותו מייל (למשל תוספת חד-פעמית) — הכמויות מצטברות.
   - `Days left` — עמודת עזר אופציונלית שמתעדכנת לבד ומראה כמה ימים נשארו עד התפוגה. בתא D2 הדביקו:

     ```
     =IF(C2="","ללא תפוגה",IF(C2>=TODAY(),(C2-TODAY())&" ימים נשארו","פג תוקף"))
     ```

     וגררו את הנוסחה למטה לכל השורות. היא רק לצפייה שלכם בגיליון — הסקריפט לא קורא ממנה.

## שלב 2 — הוסף את ה-Script

1. בגיליון: **Extensions → Apps Script**.
2. מחק את התוכן שכבר שם, והדבק את התוכן של הקובץ [`Code.gs`](./Code.gs) שבתיקייה הזו.
3. שמור (שם הפרויקט לא משנה).

הקובץ מכיל גם פונקציה בשם `onEdit` — זהו "simple trigger" שרץ אוטומטית על כל עריכה בגיליון
(זה מה שאחראי על ההמרה האוטומטית של מספר לתאריך בעמודת Expiry). אין צורך להגדיר לו טריגר
בנפרד או הרשאות מיוחדות — הוא פועל ברגע ששומרים את הסקריפט.

## שלב 3 — פרסם כ-Web App

1. בעורך ה-Apps Script: **Deploy → New deployment**.
2. לחץ על גלגל השיניים ליד "Select type" ובחר **Web app**.
3. הגדר:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. לחץ **Deploy**, ואשר את הרשאות הגישה (יופיע אזהרת "Google hasn't verified this app" — זה תקין, זה סקריפט שלך; לחץ Advanced → Go to project (unsafe) → Allow).
5. העתק את ה-**Web app URL** שמופיע בסוף (נראה כך: `https://script.google.com/macros/s/XXXXXXXX/exec`).

⚠️ כל מי שמחזיק בקישור הזה יכול לראות את תוכן הגיליון (מיילים וכמויות), בדיוק כמו ש-`pro.txt` היה גלוי בקוד. אל תשתפו את הקישור בפומבי.

## שלב 4 — חבר לאתר

פתח את `index.html`, וחפש את השורה:

```js
const PRO_SHEET_URL = "";
```

והדבק בפנים את ה-URL שהעתקת:

```js
const PRO_SHEET_URL = "https://script.google.com/macros/s/XXXXXXXX/exec";
```

שמור, commit, push — וזהו. מעכשיו האתר קורא את מכסות ה-Pro ישירות מהגיליון. אם תשאירו את
`PRO_SHEET_URL` ריק, האתר ימשיך לעבוד כמו קודם מול `pro.txt`.

## בדיקה

אפשר לבדוק שה-endpoint עובד פשוט על ידי פתיחת ה-URL של ה-Web App בדפדפן — אמור להחזיר JSON כמו:

```json
{"rb077858@gmail.com":{"unlimited":true,"limit":0},"trial@example.com":{"unlimited":false,"limit":5}}
```

## עדכון עתידי של הגיליון

בכל פעם שעורכים שורה בגיליון (מוסיפים/מוחקים/משנים), השינוי נכנס לתוקף באופן מיידי —
אין צורך לפרוס מחדש את ה-Apps Script.

אם משנים את **הקוד** של `Code.gs` עצמו, כן צריך לעשות **Deploy → Manage deployments → ✎ Edit → New version → Deploy** כדי שהשינוי ייכנס לתוקף.
